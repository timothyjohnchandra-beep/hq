# Timothy HQ

One place to run the day: Today, Notes, People and Library, backed by a private Google Sheet.

**Set up once**
1. Open script.google.com → New project, paste `apps-script.gs`, fill in `SHEET_ID` and `TOKEN`.
2. Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone). Copy the URL.
3. Open the app → Settings → paste the URL and token → Connect.
4. Add to Home Screen (Safari: Share → Add to Home Screen; Chrome: menu → Install app).
